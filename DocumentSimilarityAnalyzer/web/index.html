    03 / METHOD

    How it works

    Four course modules, one straightforward comparison pipeline.

    MODULE 01 / DESIGN

    Prepare

    Clean text, define the analysis steps, and keep the web layer separate from the Java engine.

    MODULE 02 / STRINGS

    Find matches

    Build a suffix array, use Kasai’s LCP array, and find the longest common substring.

    MODULE 03 / DP

    Score changes

    Levenshtein edit distance counts character insertions, deletions, and substitutions.

    MODULE 06 / PARALLEL

    Compare pairs

    Optionally run independent pair comparisons on a few simple Java threads.

    Final score = 70% longest-substring score + 30% edit similarity. This is a project-defined measure, not a plagiarism verdict.
